# 微信红包气泡挂件像素对齐与防截断修复方案

## 1. 现状问题根因分析
1. **小熊顶部被截断的根本原因**：
   - 在 `src/utils/redPacketProcessor.ts` 的 `createCompositeBubblePendant` 中，原有逻辑写了 `const baseH = 118;`，并在计算顶部挂件摆放时，将顶部上沿预设过高导致计算出的 `topDrawY` 在特定对齐和缩放比例下超出了 Canvas 的绘制顶界（y < 0），直接被画板边缘截断。
   - 用户在预览画布中将小熊下边缘对齐到 96px 绿色辅助线时，由于基准高度预设为 118px，按 1.0 比例计算小熊高度超出了 96px（高度约为 118px），小熊头顶冲破了 0px 边界造成顶部被削平/截断。
   - 微信官方红包气泡挂件标准规范中：
     - **顶部气泡挂件安全区域**：高度上限为 **96px**（0px ~ 96px），下边缘与红包气泡框顶边（96px）相接。
     - **底部气泡挂件安全区域**：高度上限为 **72px**（312px ~ 384px），上边缘与红包气泡框底边（312px）相接。
2. **标尺与辅助线像素刻度偏差**：
   - 在 `RedPacketCoverMaker.tsx` 中，对齐参考线及数值微调计算未与 96px/72px 强绑定，导致用户拖拽到 96px 刻度线时，图像尺寸与画布真实渲染尺寸脱节。
3. **缺少直观的越界告警**：
   - 当用户在界面上放大缩放滑块（>1.0）或手动把挂件向上拖动使得头顶越过 0px 时，界面没有清晰的越界/截断红线警示。

---

## 2. 解决方案与修改计划

### 1) 修正核心处理算法 (`src/utils/redPacketProcessor.ts`)
- **顶部挂件基准高度调整**：
  - 将 `baseH = 118` 彻底改为 `baseH = 96`（官方安全区高度）。
  - 当缩放倍率 = 1.0 时，顶部挂件在高度方向恰好完整显示在 0px 至 96px 之间，下沿精准贴合 96px，小熊头部绝对不超界（y = 0px），彻底消除被截断问题。
- **底部挂件基准高度调整**：
  - 将底部挂件基准高度统一设为 `baseH = 72`（官方 312px ~ 384px 安全区）。
  - 当缩放倍率 = 1.0 且底部对齐开启时，上沿精准对齐 312px，下沿触达 384px。
- **防止 Canvas 绘制截断溢出处理**：
  - 在生成挂件的离屏 Canvas 以及复合气泡 Canvas 中，正确保持全局坐标映射，确保只要在 0~96px 范围内都能 100% 完整绘制并保真输出。

### 2) 优化交互微调与辅助对齐面板 (`src/components/RedPacket/RedPacketCoverMaker.tsx`)
- **基准高度与对齐刻度校准**：
  - 在第 3 步“气泡挂件”配置面板中，更新顶部挂件的高度参考说明为 `0 ~ 96px (标准高度 96px)`。
  - 更新底部挂件的高度参考说明为 `312 ~ 384px (标准高度 72px)`。
  - 提供“一键满高对齐 (96px/72px)”与“居中贴合”快捷对齐按钮。
- **实时越界告警提示 (Over-boundary Warning)**：
  - 实时计算挂件当前的顶部边界 `currentTopY` 与底部边界 `currentBottomY`。
  - 如果挂件顶部超出 0px（即 `currentTopY < 0`）或底部严重超出 96px，在预览画布上高亮红虚线并显示醒目的友好警示标签（例如：`⚠️ 顶部已超出安全区 ${Math.abs(Math.round(currentTopY))}px，微信实际展示时会被截断`）。
- **优化画布交互标尺与辅助吸附线**：
  - 保证 96px 绿色基准线和 312px 基准线与底层生成器中的实际像素严格 1:1 对应。
  - 拖拽吸附（Snap）阈值精准吸附在 96px 和 312px。

## 3. 验证与测试步骤
1. **小熊 1:1 满高测试**：
   - 载入小熊图案作为顶部气泡挂件，开启底部对齐（96px 对齐线）。
   - 验证小熊下边贴在 96px，上边最高点精确在 0px 处，头顶完整无任何截断。
2. **底部挂件 72px 测试**：
   - 载入底部挂件，验证上沿紧贴 312px，下沿完整落入 384px 范围。
3. **越界告警测试**：
   - 故意放大挂件或向上挪动，验证红虚线和越界像素警告即时生效；放回安全区后恢复绿色正常标识。
4. **编译与打包**：
   - 执行 `compile_applet`，确保 TypeScript 与 Vite 生产构建 0 错误、0 警告。
